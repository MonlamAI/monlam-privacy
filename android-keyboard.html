1. Introduction & Scope

Monlam Keyboard is developed by Monlam Tibetan IT Research Center to provide native Tibetan script input, symbol input, and optional Tibetan speech-to-text (STT) on Android devices.

This Privacy Policy explains what data our keyboard and companion application access, how data is processed, and your privacy choices. This policy applies to the official Android application package com.monlamai.monlamkeyboard.

2. Keyboard Input & Keystroke Handling

Absolute Keystroke Privacy: Monlam Keyboard does not log, save, upload, or sell your keystrokes.

When you use Monlam Keyboard in any application (such as messaging, banking, email, web browsers, or notes):

  • RAM-Only Processing: All keypresses are handled in volatile device memory (RAM) and directly committed to the active application using the standard Android InputConnection.commitText() API.
  • Consonant Subjoining: When typing compound Tibetan characters (e.g., using the subjoin key), the keyboard reads the immediately preceding character via getTextBeforeCursor() solely to calculate valid Unicode glyph combinations. This character inspection is transient and discarded immediately.
  • No Keystroke Telemetry: We do not track typing speed, key frequency, autocorrect corrections, or text patterns.
  • No Clipboard Access: The keyboard does not read or inspect your system clipboard.

3. On-Device Tibetan Word Suggestions

When word suggestions are enabled, candidate words appear in the bar above the keyboard rows:

  • 100% Offline Engine: Suggestions are generated entirely by an offline, on-device engine (SuggestionEngine) utilizing compiled Tibetan dictionary and n-gram files bundled directly within the app assets.
  • Local Debounced Context: The keyboard inspects the text immediately before the cursor up to 4,096 characters to evaluate contextual Tibetan word frequency. This analysis occurs with a 40 ms debounce window in local memory and is never transmitted over the internet.
  • User Preferences: Your preferred suggestion mode is saved locally in private Android DataStore preferences (ai.monlam.keyboard_preferences) and is never synchronized to the cloud.
  • Opt-Out: Word suggestions can be turned off or changed at any time in the companion app settings.

4. Voice Input & Speech-to-Text (STT)

Monlam Keyboard offers optional Tibetan voice dictation. Voice input is strictly opt-in and requires your active initiation each time.

How Voice Recording Operates (Direct Clip Pipeline)

  1. Explicit Trigger: Recording begins only when you tap the microphone key on the keyboard suggestion bar.
  2. Permission Guard: On first use, Android asks you to grant RECORD_AUDIO permission. If declined, voice input is disabled; normal keyboard typing is completely unaffected.
  3. Active Recording Indicator: SttSessionService runs as an explicit Android Foreground Service (type: microphone). A prominent, persistent notification is displayed throughout the recording so you always know when the microphone is in use.
  4. 30-Second Hard Cap: ClipWavRecorder records audio as a mono 16-bit PCM WAV file. Recording stops automatically when 30 seconds elapse or when you tap the Stop button.
  5. TLS-Encrypted Transmission: The recorded audio clip is transmitted over HTTPS (TLS) to Monlam's dedicated Speech-to-Text API endpoint at https://api-v1.monlamai.studio/api/v1/speech-to-text/.
  6. Direct Text Insertion: The transcribed Tibetan text returned by the server is inserted directly into your active text field via commitText().
  7. Automatic Termination: The Foreground Service and microphone stop immediately once the clip is processed.
Internet Usage Notice: The app uses the INTERNET permission solely to send voice clips to the Monlam STT server when you choose to dictate. Normal typing and word suggestions never use the internet.

5. Data Storage, Retention & Deletion

Local Device Storage

  • Audio Cache: The temporary recording file (cacheDir/stt-<uuid>.wav) is strictly transient. In client code (SttSessionService.kt), this file is deleted immediately in a guaranteed finally block as soon as upload succeeds, upload fails, or recording is cancelled.
  • Transcripts: Returned text is passed directly into the active app and cleared from service state. No historical transcript database or audio history is kept on the device.
  • Local App Data Deletion: Uninstalling the application or using Android "Clear Storage" permanently purges all local preference data.

Server-Side Retention & Processing

Audio clips transmitted to api-v1.monlamai.studio are processed to compute Tibetan text transcriptions.

  • Server Retention Period: Audio clips are processed in temporary memory for transcription. Server-side logs and operational artifacts are retained only as needed for service reliability and log rotation.
  • Model Training & Transcripts: Audio clips are processed strictly to return accurate Tibetan text to your device. Voice dictation data is not linked to personal user accounts or commercial marketing profiles.
  • No User Profiling: Audio is associated with a random per-clip UUID (x-idempotency-key) and the application API key; it is not linked to personal user accounts or advertising profiles.

7. Information We Do NOT Collect

For complete clarity, Monlam Keyboard does NOT access, collect, or transmit any of the following:

  • Device identifiers (IMEI, Android ID, Advertising ID, serial number, MAC address)
  • Geographic location (GPS, network location, or Wi-Fi scan data)
  • Contact lists, phone logs, SMS, or address books
  • Files, photos, media, or external documents on device storage
  • Biometric voiceprints or speaker recognition profiles
  • Browsing activity or cross-app analytics

8. Third-Party Services & Advertising

  • Zero Advertising SDKs: No ad networks (such as Google AdMob, Unity, AppLovin) are integrated.
  • Zero Analytics Trackers: No third-party usage analytics (such as Google Firebase Analytics, Facebook SDK, Mixpanel, Segment) are included.
  • Zero Crash Telemetry: No third-party crash trackers (such as Crashlytics or Sentry) are compiled in this build.
  • No Sale of Data: We do not sell, rent, or trade user data to data brokers or commercial marketers.

9. Security Measures

  • TLS Encryption in Transit: All voice dictation network calls are encrypted via TLS (HTTPS) to prevent interception.
  • Cloud Backup Disabled: Android Cloud Backup is explicitly disabled (android:allowBackup="false" in AndroidManifest.xml) to prevent sensitive keyboard state from being mirrored to unencrypted cloud backups.
  • Signature-Protected IPC: Inter-process communication between the keyboard IME and the companion service is locked with Android signature permissions, preventing rogue apps from issuing microphone commands or reading input status.

10. Your Rights & Privacy Controls

  • Revoke Microphone Permission: You can revoke microphone access at any time in Android Settings → Apps → Monlam Keyboard → Permissions → Microphone. Normal typing continues without interruption.
  • Disable Word Predictions: Open the Monlam Keyboard app → Word suggestions → select a different method or disable suggestions.
  • Switch or Disable Keyboard: Go to Android Settings → System → Languages & Input → On-screen keyboard to disable Monlam Keyboard.
  • Erase Local Data: Uninstall the application to remove all stored preferences and cached resources from your device.

11. Children's Privacy

Monlam Keyboard is a general-purpose language input tool and is not specifically directed at children under the age of 13 (or under 16 in the European Economic Area). We do not knowingly collect personal information from children. If you believe a child has submitted audio without parental consent, please contact us for immediate assistance.
